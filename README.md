# EGB & Inflation Trading Dashboard

Python/Streamlit dashboard developed as a personal project following discussions with an EGB & Inflation Trading desk.

The application covers sovereign yield curves, relative value, inflation products, fixed income pricing and portfolio risk, with dedicated sections for Core EGB, Southern EGB, Inflation Trading and Semi-Core.

Market data is retrieved from public sources including the ECB, Bundesbank, Banque de France and Eurostat.

**Live application:** https://egb-inflation-trading-dashboard.streamlit.app
